# Data Warehosue in  MicroSoft_Fabric

Similar to  SSMS data warehouse, the Fabric Data Warehouse also contains schemas, databases, views, stored procedures, and security configurations. 

It supports SQL-based querying and follows the same relational, table‑based structure.

It is designed for analytics workloads while integrating tightly with the rest of the Fabric ecosystem.

- warehouse is  built on OneLake.
  
- Directly connects to Power BI semantic models.
  
- Use Notebooks for advanced transformations or ML.
  
- Use Pipelines for orchestration and scheduling.
